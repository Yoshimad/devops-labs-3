## Теоретические сведения
В Linux действует принцип «молчит, значит работает»: если команда выполнена успешно и не требует вывода текста, она ничего не пишет на экран. Выводятся только ошибки и предупреждения.
Для выполнения административных задач используется утилита `sudo` (Superuser DO), которая позволяет обычному пользователю выполнить команду с правами суперпользователя (root). При вводе пароля в терминале символы не отображаются в целях безопасности. 
В операционной системе Ubuntu по умолчанию отсутствует аккаунт root, поэтому все административные действия выполняются через `sudo`. Группа пользователей, имеющих право использовать `sudo`, в современных версиях Ubuntu называется `sudo` (в более старых версиях использовалась группа `admin`).
Для получения краткой справки по любой команде можно использовать ключ `--help` (например, `ls --help`), а для полной документации — утилиту `man`.

### 1. Изучение базовых команд (пункт 4 задания)
Были выполнены и изучены следующие команды:
- `date` — выводит текущую дату и время.
- `oclock` — вызывает графические часы.
- `finger` — отображает информацию о пользователях системы.
- `sudo hwclock` — показывает время аппаратных (интегрированных) часов. *(Примечание: в виртуальной среде VirtualBox при первом запуске команда может выдать ошибку `cannot access hardware clock`. После установки пакета `util-linux-extra` команда отработала корректно).*
- `uname` — выводит информацию об используемой операционной системе (ядре).
- `history` — показывает пронумерованный список ранее введенных команд.
- `clear` — очищает экран терминала.
- `ls` — выводит список файлов и каталогов в текущей директории.

### 2. Создание нового пользователя и добавление в группу (пункт 5 задания)
Был создан новый пользователь `student`:
```bash
sudo adduser student
```
В процессе выполнения система запросила и подтвердил пароль для нового пользователя, а также данные профиля (ФИО, телефон и т.д., которые были пропущены нажатием `Enter`).

Затем пользователь был добавлен в группу администраторов. В Ubuntu 22.04 эта группа называется `sudo`:
```bash
sudo usermod -aG sudo student
```
Чтобы убедиться, что пользователь успешно добавлен в группу, была использована команда:
```bash
groups student
```
В выводе команды среди прочих групп присутствует `sudo`, что подтверждает успешное предоставление прав администратора.

![Создание пользователя и добавление в группу](images/lab3_2.png)

Далее был выполнен вход под новым пользователем:
```bash
su - student
```
После ввода пароля приглашение командной строки изменилось, что подтверждает вход под новой учетной записью. Проверка текущего пользователя:
```bash
whoami
```

![Вход под новым пользователем](images/lab3_3.png)

### 3. Изучение незадействованных команд (пункт 6 задания)
Из таблицы 2 были изучены и опробованы следующие команды:
- `hostname` — выводит имя компьютера в сети.
- `uptime` — показывает текущее время, время работы системы, количество пользователей и среднюю загрузку процессора.
- `users` — выводит короткий список пользователей, работающих в системе в данный момент.
- `ps aux` — выводит подробный список всех запущенных процессов в системе.
- `free -h` — показывает информацию о свободной и используемой оперативной памяти в удобном для чтения формате.
- `ifconfig` — отображает состояние сетевых интерфейсов (IP-адреса, маски и т.д.).
- `less /etc/passwd` — используется для постраничного просмотра текстовых файлов (выход из режима просмотра осуществляется клавишей `q`).
- `mkpasswd` — генерирует надежный случайный пароль.
- `halt`, `poweroff`, `reboot` — команды для корректного завершения работы или перезагрузки системы (требуют прав `sudo`).
- `write` — позволяет отправить сообщение другому пользователю, находящемуся в системе.
